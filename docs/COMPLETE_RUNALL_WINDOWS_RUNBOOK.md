# RAMS Windows full evaluation

Use the README inside
[`RAMS_Windows_validation.zip`](../packages/RAMS_Windows_validation.zip) for a
clean-machine, download-to-results procedure. It is the authoritative Windows
operator document.

After calibration, its full-run command invokes the current phased protocol:
idle and light replay, moderate replay and Pareto, heavy replay and Pareto,
process-isolated burst replay, measured tier and policy accuracy, and
VRU-retention sensitivity. The common methodology and constraints are in
[REPRODUCIBILITY.md](../REPRODUCIBILITY.md).
